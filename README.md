# GoIT JS Homework 01 - Basics of JavaScript
JavaScript homework assignment for the GoIT course (Module 1). Topic: basic syntax, functions, arithmetic operations, template strings, and returning values.

**What was done:**
- Set up the repository `goit-js-hw-01` and configured the project structure according to the course requirements
- **Task 1 (Droid Purchase):** Implemented the `makeTransaction` function to calculate the total cost of ordered droids (`quantity * pricePerDroid`) and return a formatted string using template literals
- **Task 2 (Goods Shipping):** Implemented the `getShippingMessage` function to calculate the total shipping cost including the product price and delivery fee (`price + deliveryFee`), returning a formatted summary string
- **Task 3 (Element Width Calculation):** Implemented the `getElementWidth` function to calculate the total width of a DOM element using the box-sizing formula (`content + padding * 2 + border * 2`), handling both integer and floating-point numbers
- Verified code formatting with Prettier and ensured zero errors or warnings in the browser console across all tasks via GitHub Pages

# Домашнє завдання 01 GoIT JS — Основи JavaScript
Практичне завдання з курсу JavaScript від GoIT (Модуль 1). Тема: базовий синтаксис, функції, арифметичні операції, шаблонні рядки та повернення значень.

**Що зроблено:**
- Створено репозиторій `goit-js-hw-01` та налаштовано структуру проєкту відповідно до вимог курсу
- **Задача 1 (Замовлення дроїдів):** Реалізовано функцію `makeTransaction`, яка обчислює загальну вартість замовлення (`quantity * pricePerDroid`) та повертає відформатований рядок за допомогою шаблонних рядків
- **Задача 2 (Доставка товару):** Реалізовано функцію `getShippingMessage`, яка розраховує загальну вартість доставки з урахуванням ціни товару та комісії (`price + deliveryFee`), повертаючи готовий текстовий звіт
- **Задача 3 (Ширина елемента):** Реалізовано функцію `getElementWidth` для обчислення загальної ширини елемента за формулою моделі вмісту (`content + padding * 2 + border * 2`), з підтримкою цілих і дробових чисел
- Перевірено форматування коду за допомогою Prettier, а також відсутність будь-яких помилок чи попереджень у консолі на живій сторінці GitHub Pages
